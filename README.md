# Loyalty Predict: previsão de engajamento

🚧 **Projeto em andamento.** Última atualização: 14/11/2026.

## Objetivo
Identificar perda ou ganho de engajamento de usuários de uma comunidade
a partir do histórico de pontos e atividades.

## Dados
Datasets públicos no Kaggle: https://www.kaggle.com/datasets/teocalvo/teomewhy-loyalty-system
                             https://www.kaggle.com/datasets/teocalvo/teomewhy-education-platform

## Plano
- [ ] Exploração e definição do ciclo de vida dos usuários
- [ ] Feature engineering
- [ ] Treino e comparação de modelos
- [ ] Registro dos experimentos no MLflow
- [ ] App de inferência (Streamlit)

# Créditos e contribuições

Projeto desenvolvido a partir do curso do [Téo Me Why](https://teomewhy.org).
A estrutura das queries e a definição do ciclo de vida seguem o curso.
